扫码助手 v0.1.6（P0）

1. 把「扫码助手」拖到 Applications 文件夹
2. 打开 Applications 里的「扫码助手」
   如果之前在 DMG 里打开过，请先在菜单栏退出旧实例，再从 Applications 打开，避免同时运行两份
3. 如果 macOS 提示“无法验证开发者”：
   右键 App → 打开；或到「系统设置 → 隐私与安全性」里点“仍要打开”
4. 首次使用请在「系统设置 → 隐私与安全性 → 屏幕录制」允许「扫码助手」
5. 先手动打开百度网盘 / 夸克（工具不会替你启动）
6. 按 ⌃⌥Q，框选屏幕上的二维码，点「解析二维码」

如果屏幕录制列表里已有旧的「扫码助手 / ScanCode」条目但授权不生效：
先选中旧条目点减号删除，再打开 App；App 启动时也会自动清理旧授权并重新请求。
如果授权开关看起来是开的但仍无法截屏：在菜单栏图标里点「修复屏幕录制权限…」。
App 启动时也会做一次实际截屏自检，发现旧授权不生效会自动清理并重新请求。

说明：
- 只唤起已经打开的应用，不冷启动
- 只打开，不自动保存/转存；保存按钮由你在官方客户端点
- 截图只在本机处理，不上传

开发/源码构建请见项目 README。
